# Stress Test

Поле конфликта: `desired_course`.

Схема требует одно из фиксированных значений `Literal[...]`, а промпт требует придумать новый оригинальный курс и прямо запрещает использовать значения из схемы.

- `max_retries=0`: **failed** за 17.2 сек.; ValidationError: 1 validation error for Application

## Вывод

При малом числе ретраев конфликт проявлялся как ошибка, но при `max_retries=1` модель подчинилась JSON-схеме и выбрала разрешенный курс. Это показывает, что retry иногда спасает, но ценой лишних запросов и без гарантии.
